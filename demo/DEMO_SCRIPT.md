# Recorded demo script

**Target length: 2 minutes 45 seconds.** Use only independently prepared synthetic material. This is a recording plan, not evidence that a public demo environment exists.

## Preparation

Use a separate, authorized demonstration environment or clearly labeled reconstruction. Do not modify either private product repository or connect a recording session to the live Sheet, private library or production services. If such an environment is unavailable, use synthetic storyboard frames and label them “Illustrative workflow”; do not present them as a live execution.

Use the invented opportunity “Civic service learning review,” organization “Lumen Public Initiatives,” country “Valmera,” and configured demonstration keywords “civic learning” and “aprendizaje cívico.” See [synthetic materials](../examples/SYNTHETIC_DEMO.md). All supporting rows and document contents must also be invented. Prepare more rows than one page can display so pagination is visible; do not invent a product usage count.

Hide browser chrome, URL bars, tabs, bookmarks, account avatars, desktop notifications, credentials, console output, repository paths, logs, Sheet identifiers, deployment addresses and private filenames. Replace branding with the anonymized project title. Do not open a real file picker while recording. Use cuts between pre-staged upload states.

## Recording and export checks

Capture the application content region at 1920 × 1080 where practical, with readable text at playback size. Use deliberate pauses on match explanation and human review. Label time cuts; do not imply that edited generation latency is measured performance. For a reconstruction, keep the illustrative label visible throughout.

Review every frame, including transitions, thumbnails and the final export. Check the audio for accidental client names and read the generated captions. Flatten any redactions into exported frames; a removable overlay in an editable project is not a final redaction. If any content is uncertain, fail the confidentiality gate and ask the owner to review before recording is shared. No recording or publication is authorized by this script.
